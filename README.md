## 🧠 About Me

I'm **Juna Lei G. Sionillo**, a Second Year BS Information Technology student navigating the exciting transition from writing basic scripts to building full-scale systems. 

I consider myself an **intermediate full-stack developer**—which really just means I’ve built enough projects to know how much I still have to learn, and I'm loving every bit of the exploration. My journey is all about moving past the tutorials and getting my hands dirty by trying new languages and creating projects to figure out how they actually work.

Right now, my journey lives at the intersection of powerful backends and intuitive design:
* 🛠️ **Desktop & Web:** I enjoy crafting structured PyQt6 applications and web systems in Laravel, always obsessing over clean code and strict MVC architecture.
* 🎨 **User Experience:** I believe software should be as delightful to look at as it is functional. I put a lot of effort into making sure the UI doesn't make people want to immediately close the tab.

I don't just read documentation cover-to-cover; I pick a tool I don't know, dream up a project, and build it until it makes sense. Every repo here is another chapter in my learning story.

- 👨‍💻 All of my projects are available at [github.com/paradoxxal88](https://github.com/paradoxxal88)

## 🚀 Projects

### Stockra — Inventory Management System

Stockra is a responsive, web-based inventory management system built with Laravel and MySQL, purpose-built for tracking computer hardware components. It features role-based access control distinguishing Admin and Staff workflows, real-time stock monitoring with low-stock alerts, and automated updates on delivery receipts. Powered by Eloquent ORM and a Bootstrap-driven UI, Stockra delivers accurate, multi-device hardware cataloging with full transaction logging for audit transparency.

[View Project →](https://github.com/paradoxxal88/CompShop_Management-System)

### Attendify — Attendance Monitoring System

Attendify is a Python-based employee attendance monitoring system built with PyQt6 and MySQL, purpose-built for streamlining daily check-ins and check-outs in medium-sized organizations. It features role-based access control distinguishing Admin and Employee workflows, real-time attendance recording, and automated generation of weekly and monthly punctuality reports. Powered by a centralized database on XAMPP and an intuitive Qt Designer-driven interface, Attendify delivers accurate, digital attendance logging with secure historical tracking to minimize manual errors and administrative overhead.

[View Project →](https://github.com/jsionillo558815-cmyk/Sionillo_AttendanceMonitoringSystem-IT5)
